
# Face Detection Using OpenCV

A Python project for **real-time face detection** using OpenCV’s Haar Cascades. The program captures video from your webcam, detects faces, and draws bounding boxes around them.

---

## Features

- Real-time face detection from webcam
- Uses Haar Cascade Classifier
- Draws rectangles around detected faces
- Modular Python code for easy enhancements
- Optional: Can be extended to mask detection or emotion recognition
